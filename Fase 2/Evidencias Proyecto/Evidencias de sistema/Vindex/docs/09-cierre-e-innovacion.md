# Cierre e innovacion

## Resultados

Vindex entrega una base de marketplace web con autenticación, catálogos, tiendas, carrito, mensajería, administración y checkout sandbox. Las subastas y el OTP están integrados parcialmente o dependen de migraciones y configuración remota de Supabase.

## Trabajo pendiente

- Completar cierre y pago de subastas.
- Implementar custodia y liberación productiva.
- Implementar recargas y retiros reales.
- Integrar notificaciones completas de pujas.
- Definir despliegue reproducible con Docker si se aprueba.
- Medir rendimiento y disponibilidad en un ambiente desplegado.

## Innovación

La propuesta combina marketplace tradicional y subastas en un entorno diseñado para comercio independiente chileno. La diferenciación planificada se basa en la trazabilidad de la operación, la coordinación de entregas y un modelo financiero transparente. Las funciones reales deben distinguirse siempre de las estimaciones o objetivos futuros.
