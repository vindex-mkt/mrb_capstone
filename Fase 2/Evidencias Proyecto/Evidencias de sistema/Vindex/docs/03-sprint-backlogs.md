# Sprint Backlogs

El proyecto se desarrolló mediante Scrum, con iteraciones centradas en infraestructura, marketplace, carrito, subastas, pagos y cierre de calidad.

| Sprint | Objetivo |
|---|---|
| 1 | Monorepo, Supabase y autenticación |
| 2 | Catálogo y CRUD de publicaciones |
| 3 | Carrito e inventario |
| 4 | Publicación y modelo de subastas |
| 5 | Pujas y sincronización Realtime |
| 6 | Checkout y pagos sandbox |
| 7 | Administración y notificaciones |
| 8 | QA, integración y preparación del MVP |

Cada Sprint debe registrar historia, responsable, estado, criterio de aceptación y evidencia verificable. La planificación y el detalle historico están consolidados en [Marco Ágil.md](./Marco%20Ágil.md).
