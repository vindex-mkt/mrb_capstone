# Product Backlog

El backlog prioritizado se organiza por valor de usuario y riesgo técnico.

## Backlog implementado o parcialmente implementado

| Prioridad | Historia |
|---|---|
| Alta | Registro, inicio y recuperación de sesión con Supabase Auth |
| Alta | Crear y editar perfiles y tiendas |
| Alta | Catálogo, categorías y publicaciones |
| Alta | Carrito persistido y sincronizado |
| Alta | Checkout Webpay Plus Mall de integración |
| Alta | Moderación administrativa de publicaciones |
| Media | Mensajería y notificaciones |
| Media | Subastas con RPC y Supabase Realtime |
| Media | OTP de retiro presencial |

## Backlog pendiente

- Escrow real y liberación de fondos.
- Finalización y pago completo de subastas.
- Notificaciones de puja superada y ganador.
- Recargas y retiros reales de billetera.
- Eliminación definitiva de productos.
- KYC y verificación de identidad.
- API NestJS como backend independiente.
- Docker, Redis y despliegue reproducible mediante contenedores.
