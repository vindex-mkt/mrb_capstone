# Definition of Done

Una historia se considera terminada cuando cumple todos los puntos aplicables:

- Código TypeScript aprobado por lint y compilación.
- Implementación revisada mediante control de versiones.
- Criterios de aceptación funcionales verificados.
- Migraciones, RPC, RLS y triggers aplicados y probados cuando existan cambios de base de datos.
- Estados de carga, error y ausencia de datos considerados en la interfaz.
- Prueba automatizada o manual ejecutada y registrada.
- Credenciales reales excluidas del repositorio.
- Documentación técnica actualizada con el cambio.

Detalles por funcionalidad y criterios específicos están en [Marco Ágil.md](./Marco%20Ágil.md).
